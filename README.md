** About This Project

Guess My Number is a simple game built with HTML, CSS, and JavaScript.

The player must guess a secret number between 1 and 20.

The game gives hints to help the player guess the correct number.

** Technologies Used

* HTML
* CSS
* JavaScript

** How to Play

1. Enter a number between 1 and 20.
2. Click the Check button.
3. Read the hint.
4. Keep guessing until you find the correct number.
